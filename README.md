# my_learn

This project demonstrates a small web page that allows you to draw curves by selecting points. You can configure axis ranges, import or export `.dat` files and clear the plot. Points can be moved, deleted, copied or rotated and basic undo/redo operations are supported.

Open `index.html` in a browser to try the demo. For details on advanced features and implementation notes see `CURVE_EDITOR_MANUAL.md`.
